# web

The Commish prep site: one SvelteKit app (Svelte 5 runes, TypeScript strict) on Cloudflare Workers
static assets through `@sveltejs/adapter-cloudflare`. Nightly pages are prerendered at build. User
pages are client-rendered and talk to the Go API. The spec is
`docs/superpowers/specs/2026-10-12-prep-site-architecture-design.md`, section 2.1.

This folder has its own `package.json`. The repository root's is the Next.js app being retired.

## Run

```sh
cd web
npm install
npm run dev            # http://localhost:5173, the system page at /system
```

## Build and gates

```sh
npm run check          # wrangler types, svelte-kit sync, svelte-check
npm run lint           # Prettier, then ESLint with typescript-eslint strictTypeChecked
npm run build          # wrangler types, then vite build into .svelte-kit/cloudflare
npm run preview        # the built Worker under wrangler dev at http://localhost:4173
npm run lighthouse     # Lighthouse CI against the preview, budgets in lighthouserc.json
npm run screenshots -- http://localhost:4173/system system   # both themes at 1440 and 390, into screenshots/
```

`worker-configuration.d.ts` is generated by `wrangler types` on every check and build and is not
committed: once a build exists, wrangler adds a type import of the built worker to it, so a
committed copy goes stale after the first build. `checkJs` is off for the same reason, so the built
worker's JavaScript is never type-checked as if it were ours. Everything we write is TypeScript.

## Budgets

`lighthouserc.json` carries the spec's budgets at the mobile profile (150 ms round trip, 1.6 Mbps,
4x CPU), applied throttling, five runs, asserted on the median. Prerendered pages: LCP 1.2 s, script
transfer 60 KB. User pages (sheet, mock, lobby, report, account, pass): LCP 2.0 s, script 180 KB.
CLS 0.05 everywhere. Only the system page is collected until the product routes exist.

## Tokens and primitives

`src/lib/ui/tokens.css` is the token set of the approved design authority,
`docs/design/mocks/2026-10-12-commish/tokens.css`, copied verbatim in the same three blocks: light on
bare `:root`, dark under `prefers-color-scheme` guarded by `:root:not([data-theme="light"])`, and
dark again under `:root[data-theme="dark"]`. Change a token there first, then here.

The primitives in `src/lib/ui/` port the mock's `build/shell.py` and `build/roomparts.py`, one
component per file with typed props. Every color is a token, and no page styles a primitive from the
outside. The system page at `/system` renders each of them with the mock's real 2026 PPR rows from
`src/fixtures/mock-2026-ppr.ts`, the only fixture in the app.

## Fonts

Google Fonts' Outfit and Big Shoulders Display for the UI, Newsreader for capsule prose, all
self-hosted from the Fontsource packages of the same files so the first paint never waits on a
cross-origin stylesheet. `scripts/subset-fonts.ts` (`npm run fonts`) cuts the two UI faces to a core
character set and writes `src/lib/ui/fonts/ui.css` and `src/lib/ui/fonts/core/`. Commit its output.
Any character outside the core falls through to the full Latin files, which load only when needed.
`src/lib/ui/fonts/read.css` holds Newsreader and is imported only by a component that sets prose.

## Headshots

`src/lib/ui/headshot.ts` asks ESPN's image combiner for each face at its drawn size at 1x and 2x,
about 10 KB a face instead of the 260 KB original.
