# Fit Round Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every open pricing question (rookie curve on the full cohort, blend on the honest law family, props anchor, recency availability, law-channel semantics) answered by ONE fit and ONE held-out verdict, with the old decade's rosters and team map landed first and the family re-measured once.

**Architecture:** Strict sequence: data prep -> one re-measure event -> fit-harness extensions (code only) -> one grid fit on train -> one held-out scorecard -> v8 board only if the bar holds. The held-out seasons are structurally unreachable from the fit's objective.

**Tech Stack:** TypeScript, Postgres/Drizzle, vitest (serial only), nflverse + curated vegas + The Odds API archive (already ingested).

**Spec:** `docs/superpowers/specs/2026-09-02-fit-round-design.md`

- ONE vitest runner, `--no-file-parallelism`. No em-dashes printed/rendered. Tri-state. Figures from runs. Leakage gates ordinary. Published-beats-derived. Live tables retire their previous claim. The held-out set selects NOTHING (fit objective = train only; pinned by test). Drift protocol total after every store-growing task. THE BAR: decisive-2024 blend vs ADP BEYOND NOISE, interval excluding zero; bar breaks = STOP, incumbent v7 stands, the negative ships in the close-out.
