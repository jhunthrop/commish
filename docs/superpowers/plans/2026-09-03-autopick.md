# Need-aware autopick — plan

Spec: `docs/superpowers/specs/2026-09-03-autopick-design.md`. TDD throughout, small commits,
branch `worktree-autopick`, no merge.

## Steps

1. **Docs first** — commit spec + this plan.
2. **Extraction (RED→GREEN)** — new `src/draft-engine/scoring.ts` with
   `rankWeight`/`openStartingSlots`/`needMultiplier` as pure parameterized helpers +
   `scoring.test.ts`. Export from the engine barrel.
3. **Bot refactor (equivalence)** — `src/mock-draft/bots.ts` consumes the shared helpers with
   zero behavior change; its existing tests stay green untouched except imports.
4. **Engine config** — `AUTOPICK_CONFIG` in `src/draft-engine/config.ts` (temperature 3.0,
   needPerOpenStartingSlot 0.4, startersFilledDamp 0.6, rampFullAtRosterFraction 0.5),
   exported from the barrel.
5. **Selector upgrade (RED→GREEN)** — `bestAvailableFor` fallback becomes the deterministic
   need-aware argmax with the linear roster-length ramp; new `bestNominationFor` keeps the
   queue-then-board-order behavior for the auction; `auction.ts` switches to it. New
   `autopick.test.ts` covers: round-1 purity (top-ranked despite a filled position),
   late-round need fill (round 8, four RBs, no TE: the TE beats a higher-ranked fifth RB),
   cooling (filled-starters position loses to open-need position of comparable rank),
   determinism (same state → same pick, twice), queue-beats-everything, tie-break by board
   order, and the endgame regression (full 15-round all-autopick draft ends with every
   starting slot filled — alongside `full-draft.test.ts`, which now exercises the new scoring
   end to end).
6. **Auction pinned** — test that auto-nomination still nominates queue-first then board-order
   even when the nominator has a screaming positional need.
7. **Copy** — league-rules page, room dock, room tour, join sheet: "your queue first, then the
   best player your roster needs". No em-dashes.
8. **Gates** — tsc 0, eslint clean, draft-engine + draft-service + mock-draft + quilt suites
   green. Retry flaky shared-DB lanes.

## Non-goals

- No change to auction economics, legality (`assignSlot`), skip-and-owe, or the bots' sampler.
- No RNG anywhere in the autopick path.
