# Sunday v5 — the rooms track's test ledger

Tests are deferred for this campaign by founder ruling; `npx tsc --noEmit` is clean on production
files at every commit on this branch. This file is the list of test files the rooms track
knowingly broke, what changed under them, and what the replacement assertion should pin. One line
of intent per file, so whoever re-writes them is not reverse-engineering the design from a diff.

Surfaces: the live draft room (`/app/drafts/[draftId]`), the TV board (`/draft/[draftId]/board`),
the mock-draft lobby and rooms, and the join/hold doors.
