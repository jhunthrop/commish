## Other judgment calls

- **`PlayerObject`'s own POS/team chips were left untouched.** The mock's literal example string ("WR · NYG · Bye week 8 · …") would restate position and team as text, duplicating what `PlayerObject` (a shared primitive used by the full page too) already shows as chips. Modifying that shared primitive is Task 6 territory (the full page) and risks a wider, unreviewed blast radius, so the new identity line states only the two facts `PlayerObject` does NOT already show: bye week and roster status.
- **`SourceStrip` is removed from the dossier-present branch** (not mentioned anywhere in the coordinator's described composition order, and `CallCard`'s three price columns cover the identical market/board comparison). It still renders, unchanged, in the fallback branch. No existing test referenced `SourceStrip`'s own cell labels directly, so this was safe to confirm by running the existing suite.
- **`ReadCard` can render `null`** when `body.capsule` is absent, and — being a CSS grid child — an absent card does not reserve its cell, so `BooksModule` would visually sit alone in that row rather than paired on the right. This is the same "absence renders nothing" law every other module here keeps; flagging the visual side effect rather than adding cell-reservation logic nobody asked for.
- **`SeasonStrip`'s five facts always describe LAST season** (`dossier.lastSeasonStory`, fixed), while its embedded `weeks`/chart still respects the season switcher (`weeksFor(body)`, whichever season `body.season` currently resolves to) — an inherent consequence of `PlayerFactsLastSeasonStory`'s own "last season, always" semantics (Task 1/2), not something this task introduced. When `lastSeasonStory` is `null` (a board-ranked rookie, most often), that grid cell falls back to the exact pre-dossier rookie/no-record/chart branch (`SeasonChartFallback`, shared code, not duplicated).
- **The header's designation pill is intentionally NOT deduplicated against `StoryModule`'s own pill** — per the coordinator's explicit instruction, both may say the same thing at once. Tested (`getAllByText("Q")` has length 2).
