# The record's fixtures

Generated by shared/scripts/export-record.ts from web/scripts/record-fixture/record-live.json and web/scripts/record-fixture/two.ts. Do not edit: edit the source and run `npm run gen:shared` in web/.

The run's record file (`record.json`, the `record` field of `GET /run/record`) with the weekly
and draft records the nightly writes beside the run's own since Lane 114, for the apps' Our record
screen and its parity (`shared/fixtures/parity/record.json`). Week 7 graded is a STAND-IN made by
`web/scripts/record-fixture/two.ts` from the live record's week 2: its figures are not a grade of anything. The contract
run's own record (`shared/fixtures/run`) is the record before Lane 114, with neither.

| File | What it holds |
| --- | --- |
| `waiting.json` | the run's own record alone, week 6 set and waiting on its stats with the day it usually grades |
| `upcoming.json` | the weekly record before its first week is set, and the draft record |
| `set.json` | the weekly record with week 7 set and played, waiting on its stats with the day it usually grades, and the draft record |
| `graded.json` | the weekly record with a STAND-IN week 7 graded against ESPN, and the draft record |
| `published.json` | the STAND-IN week 7 with the week's published projection graded beside ESPN, and the draft record |
