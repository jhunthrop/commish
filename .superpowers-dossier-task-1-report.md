## Row-scoping

Genuinely row-scoped (single WHERE clause or an array-of-one call to an already-parameterized
helper), replacing `boardRows`'s whole-board join + value/tier recompute entirely (safe because
`factsInputFor` never reads a shape-dependent `BoardRow` field):
- `players` identity, `WHERE id = playerId`
- `nflPlayerIdsFor(db, [playerId])`
- `preseasonProjectionsFor(db, stamp, [nflPlayerId])` (the player-scoped sibling of
  `preseasonProjectionsAsOf`)
- `newsForPlayers(db, [name])`, `currentSeasonSummaries(db, [playerId], …)`

Narrowed to the target's own position (not the whole board) for the ranking-dependent color facts:
`lastSeasonStoriesFor` and `usageTouchesAndTrendFactsFor` both bucket their `positions` input BY
POSITION internally (`rankWithinGroups`, `pooledDiscoveryValuesByPosition`), so restricting that
map to only the target's peers before calling them is mathematically identical to passing the
whole board — proven by the peer-plus-different-position fixture in the test. This is the real
win against the whole-board-read-per-peek debt: the expensive per-position stat-line/participation
reads now run for one position's peers, not every skill position combined.

## Reads that stayed board/team-wide (documented in the module docblock)

- `allPositions(db)` — every `nfl_players` id-to-position row; needed even for the position-narrow
  above, since "who else plays his position" requires knowing every player's position first. No
  player- or position-scoped query exists. Small table, not a stat read.
- `boardReasons(db, BOARD_SOURCE, PRODUCT_SEASON)` — no player-scoped variant in the store; read
  whole then indexed down to the one player.
- `propsLinesByPlayer(db, PRODUCT_SEASON)` — `loadArchivedPropLines` has no player filter; read
  whole then indexed down.
- `vegasWinTotalsByTeam` and `byeWeeksByTeam` — team-keyed, already small (32 teams), no
  team-scoped reader exists.
- `injurySnapshot(db)` — a single `LIMIT 1` snapshot row; already as narrow as the store allows,
  its JSON payload just happens to name every player.
